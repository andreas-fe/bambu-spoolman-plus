# Aktuelle Screenshots

Stand: 17. November 2026. Die PNG-Dateien wurden mit einem Browser aus den aktuellen Python-/Jinja-Vorlagen dieser Anwendung gerendert. Produkte, Hersteller, Rollen, Auftragsnamen, Journalzeilen und Energiemesswerte sind ausschließlich künstliche Dokumentationsdaten. Es wurden keine produktiven Datenbanken, privaten Konfigurationen oder Kameraaufnahmen verwendet. Die Aufnahmen lösten keine Geräteaktionen aus.
