# Aktuelle Screenshots

Stand: 16. November 2026. Die zehn PNG-Dateien wurden mit einem Browser aus den aktuellen Python-/Jinja-Vorlagen dieser Anwendung gerendert. Produkte, Hersteller, Rollen, Auftragsnamen, Journalzeilen und Energiemesswerte sind ausschließlich künstliche Dokumentationsdaten. Es wurden keine produktiven Datenbanken, privaten Konfigurationen oder Kameraaufnahmen verwendet. Die Aufnahmen lösten keine Geräteaktionen aus.

| Datei | Bereich |
|---|---|
| printer.png | A1-Status, Fortschritt, Restzeit und aktiver Schacht |
| ams-lite.png | Grafisches AMS Lite, Rollenwahl und Material-/Farbvergleich |
| spools.png | Suchbare physische Spulen |
| products.png | Produktstammdaten einschließlich Leerspulengewicht |
| weighing.png | Ausgefüllte Wiegekorrektur mit Rechenvorschau |
| journal.png | Beispielbuchungen, Abbruch und manuelle Korrektur |
| camera.png | Kamera geschlossen, Lichtschalter oberhalb der Bildfläche |
| power.png | Tapo-Bedienung und künstliche Messwerte |
| auto-power-off.png | Auftragsbezogene Abschaltung mit Verzögerung |
| settings.png | Simulation, Zuordnung und deaktivierter Flusszuschlag |

Die Gerätezustände sind Beispieldaten und kein Hardwaretestnachweis. Die Kamera bleibt bewusst geschlossen; das Bild enthält keinen künstlich als Livebild ausgegebenen Stream. Der Stand der Hardwareprüfungen steht in [DEPLOYMENT.md](../../../DEPLOYMENT.md). Die ältere Aufnahme `../gui-v2.4.3.jpg` ist eine historische Oberfläche und beschreibt nicht den heutigen Plus-Stand.
